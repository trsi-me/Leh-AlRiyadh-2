# ليه الرياض؟ (المجلد 2)

## 1. ما هو المشروع؟

هذا المجلد نسخة ملفات من `D:\VSCode\Projects\Leh AlRiyadh`. الموقع عربي عن الرياض، والصفحة الرئيسية `index.php` عنوانها «ليه الرياض؟ - اكتشف جوهر العاصمة السعودية». التعليقات تُحفظ في MySQL. الاسم في README السابق داخل المجلد: Why Riyadh?

مقارنة المجلدين: نفس قائمة الملفات النسبية (204 ملفًا مشتركًا). لا ملفات زائدة في أحدهما. الفرق الوحيد في محتوى الملف ظهر في `assets/images/Logo.png`: 389442 بايت في هذا المجلد، و 159917 بايت في `Leh AlRiyadh`.

## 2. لماذا يوجد هذا المشروع؟

نفس هدف المجلد الأول كما تصفه الصفحة وREADME السابق: التعريف بالرياض سياحيًا وثقافيًا. سبب وجود مجلد ثانٍ غير موثق في الملفات. استنتاج من الكود: النسخة مطابقة وظيفيًا مع اختلاف الشعار فقط.

## 3. من يستخدمه؟

زائر يقرأ ويشاهد الوسائط ويرسل تعليقًا. لا دور مدير ولا حسابات.

## 5. كيف يعمل النظام؟

```
index.php
  -> include get_comments.php
  -> POST add_comment.php
  -> config.php
  -> MySQL leh_alriyadh.comments
```

الملف الرئيسي `index.php` لا `index.html`. لا `style.css` ولا `script.js` في الجذر، خلاف README السابق المنسوخ مع المجلد.

## 6. أمثلة واقعية

إرسال تعليق، وهو نفس منطق الملفات المطابقة:

1. النموذج `commentForm` يرسل `name` و `message` إلى `add_comment.php`.
2. الرفض: `empty_fields` أو `name_too_long` (أكثر من 255) أو `message_too_long` (أكثر من 5000).
3. النجاح: توجيه إلى `index.php?success=comment_added#comments`.
4. العرض: آخر 50 تعليقًا، التاريخ `Y-m-d H:i`.
5. `database.sql` يبذر ثمانية تعليقات تجريبية.

فتح صفحة معلم مثل `tourist/natural-landmarks/index.html` يعرض HTML ووسائط بلا كتابة في القاعدة.

## 7. رحلة المستخدم

## 19. الخادم

`config.php`: مضيف `localhost`، قاعدة `leh_alriyadh`، مستخدم `root`، كلمة مرور فارغة في الملف، ترميز `utf8mb4`. فشل الاتصال يطبع «خطأ في الاتصال بقاعدة البيانات» مع نص الاستثناء.

`add_comment.php` جملة محضّرة. `get_comments.php` يقرأ آخر 50 صفًا.

## 20. مسار الطلب

```
POST add_comment.php
  -> تحقق

  -> Redirect #comments
  -> get_comments.php يرسم HTML
```
